Syntax
public class AppMethod : Method, ICommand
Remarks

This class extends the base Method implementation to support custom variable creation, return value handling, and relaxation of internal method restriction counters enforced by the BOOSE framework.

AppMethod()

public AppMethod()
Remarks

The constructor attempts to reset internal static restriction counters defined in the base Method class using reflection. This allows multiple method declarations to be compiled without triggering framework-imposed limits.

Remarks

After invoking the base compilation logic, this method creates:

  • A return variable named after the method, based on its declared return type.
  • Variables for each declared local parameter, using their specified types.
All variables are registered with the program’s variable store.
