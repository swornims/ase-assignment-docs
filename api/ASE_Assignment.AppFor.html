    Class AppFor

    Represents a for loop command that iterates over a numeric range.

    Inheritance
    System.Object
    AppFor
    Namespace: ASE_Assignment
    Assembly: ASE_Assignment.dll
    Syntax
    public class AppFor : ConditionalCommand
    Remarks

    The expected syntax is:

    for variable = start to end step increment

    The loop initializes the control variable, evaluates range expressions, and relies on the corresponding end for command to manage iteration.
