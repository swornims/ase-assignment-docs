Namespace ASE_Assignment

Classes

AppArray

Represents a one- or two-dimensional array variable within the BOOSE execution environment.

AppBoolean

Represents a boolean variable in the BOOSE language. Handles declaration, assignment, and evaluation of boolean expressions.

AppCall

Represents a call command that invokes a user-defined method with parameters within the BOOSE program execution environment.

AppCanvas

Represents a drawable canvas that supports shapes, lines, text, and color operations. Provides methods required by the BOOSE ICanvas interface. Implements the Singleton pattern to ensure only one drawing surface exists.

AppCircle

Represents the command that draws a circle on the canvas.

AppCommandFactory

Factory class responsible for creating application-specific command instances.

AppDrawTo

Represents a drawing command that draws a line from the current position of the pen to the specified (x, y) coordinates.

AppElse

Represents an else clause in a conditional control structure.

AppEnd

Represents an end command that terminates compound control structures such as conditionals, loops, and method declarations.

AppFor

Represents a for loop command that iterates over a numeric range.

AppIf

Represents an if conditional command that controls the execution of a block of statements based on a boolean condition.

AppInt

Represents an integer variable in the BOOSE language. Handles declaration, assignment, and evaluation of integer expressions.

AppMethod

Represents a user-defined method declaration within the BOOSE program model.

AppMoveTo

Represents a command that moves the pen to the specified (x, y) coordinates without drawing a line.

AppParser

Parser class for analyzing and converting BOOSE program text into executable commands. Handles variable declarations, control structures (if, while, for), arrays, methods, and drawing commands. Implements the IParser interface from the BOOSE library. Bypasses BOOSE library restrictions by resetting static counters.

AppPeek

Represents a peek command that reads a value from an array into a variable. Syntax: variable = arrayName row [column]

AppPen

Represents a command that changes the pen colour used for drawing on the canvas.

AppPoke

Represents a poke command that writes a value to an array element. Syntax: arrayName row [column] = value

AppReal

Represents a real (floating-point) variable and expression evaluation within the BOOSE execution environment.

AppRectangle

Represents a command that draws a rectangle on the canvas. Supports both filled and unfilled rectangles based on parameters.

AppStoredProgram

Represents a stored program with conditional command stack functionality. Inherits from the StoredProgram class and provides custom implementations for managing commands.

AppWhile

Represents a while loop command that repeatedly executes a block of statements while a condition evaluates to true.

AppWrite

Represents a write command that outputs text or evaluated expressions to the program's drawing canvas.

Form1

Main Windows Form responsible for initializing the BOOSE environment, handling UI events, and executing user-defined programs on the canvas.
