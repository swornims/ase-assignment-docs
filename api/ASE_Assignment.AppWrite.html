    Class AppWrite

    Represents a write command that outputs text or evaluated expressions to the program's drawing canvas.

    Inheritance
    System.Object
    AppWrite
    Namespace: ASE_Assignment
    Assembly: ASE_Assignment.dll
    Syntax
    public class AppWrite : CommandOneParameter
    Remarks

    This command accepts a single parameter, which may be either a literal string or an expression. If the parameter can be evaluated as an expression, the evaluated result is written; otherwise, the raw text is written.
