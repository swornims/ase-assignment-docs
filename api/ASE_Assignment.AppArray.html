    Class AppArray

    Represents a one- or two-dimensional array variable within the BOOSE execution environment.

    Inheritance
    System.Object
    AppArray
    AppPeek
    AppPoke
    Namespace: ASE_Assignment
    Assembly: ASE_Assignment.dll
    Syntax
    public class AppArray : Evaluation
    Remarks

    This class supports declaration, allocation, and indexed access (peek and poke operations) for integer and real arrays. Array indices and values may be expressions evaluated at runtime.
